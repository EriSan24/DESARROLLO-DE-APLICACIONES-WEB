# Proyecto_Ferreteria

Pequeña aplicación Flask de ejemplo para gestionar una ferretería (productos, clientes, proveedores y facturación).

Instrucciones rápidas:

1. Crear un entorno virtual e instalar dependencias:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

2. Ejecutar la app:

```bash
python app.py
```

Abrir http://127.0.0.1:5000/ en el navegador.
